# Assignment 4.5 - Multi-Page College Club Website

## GitHub Link

https://github.com/udaypratapsingh007/Assignment-4.5

## Description

A four-page college club website built with HTML. The pages are index.html (Home), about.html (About), registration.html (Registration) and contact.html (Contact). All pages share the same navigation bar. The home page has the club activities and an events schedule table, the about page has club details and a members table, the registration page has a form, and the contact page has the email, location and phone details. Every page has metadata and a favicon.
